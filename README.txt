TO GOLD MEDAL — Athlete Edition v2

WHAT CHANGED
- Bright, sporty interface; Home / Train / Journey / Profile.
- The Train screen has a predetermined week-by-week workout plan.
- Sunday, Tuesday, Thursday: workout sets. Other non-Saturday days: recovery.
- Saturday: guided weekly max-effort push-up and squat test.
- Tap to complete each prescribed set. Coins are calculated automatically only when the workout is complete.
- Saturday test: self-count reps, finish one push-up set, then one squat set. The app judges the weekly goal and grants the +100 bonus automatically. No manual test form.
- Profile offers device-local data and export/import backups.
- Attempts to preserve earned coins and personal bests from the previous version on the SAME hosted origin and browser (old local storage remains intact).

INSTALL / UPDATE ON GITHUB PAGES
1. Extract the ZIP.
2. Open your GitHub repo: to-gold-medal.
3. Upload all the files INSIDE the to-gold-medal-v2 folder into the repo's root (replace same-named files).
4. Commit changes and wait for Pages to deploy.
5. Open the SAME Pages link on your iPhone and refresh. If an installed home-screen app caches old code, fully close/reopen it or refresh in Safari.

NOTES
- No backend, Apple Health, camera verification or push notifications in this MVP.
- All progress is on the device/browser origin. Export a backup regularly.
- Days are based on your iPhone local time. Saturday is weekly test day; workout days are Sunday, Tuesday, Thursday.
- The plan is a prototype, not a medically individualized prescription. Progress at your own pace and stop if painful.
- Upload files, NOT the ZIP file, to GitHub.
