TO GOLD MEDAL — PERSONAL IPHONE APP (MVP)

Includes workout logging, gold coins, 12-week targets, weekend trials, best scores, ranks, full local backup/import, and an offline service worker.

HOW TO INSTALL ON IPHONE
1. Host ALL files together at a HTTPS address (GitHub Pages, Netlify, or another static web host).
2. Visit that address in Safari on your iPhone.
3. Tap Share → Add to Home Screen → Add.
4. Launch Gold Medal from your home screen. The app will cache its files for offline use.

IMPORTANT: Opening index.html directly as a local file on iPhone is not a reliable way to install a PWA. HTTPS hosting is necessary for service-worker installation. The provided ZIP is the app source, not a signed iOS .ipa file.

PRIVACY: Training data is stored using browser localStorage only. It is not uploaded to a cloud server. Use Profile → Export backup periodically. Browser data clearing may erase the information.

HOW SCORING WORKS
- Each push-up: 2 coins. Each squat: 1 coin. Each sit-up: 2 coins.
- Maximum daily workout coins: 300.
- First passing test for each of 12 weeks: +100 coins.
- The week 1 baseline is adjustable (default 1 push-up / 10 squats). Targets interpolate to week 12: 30 push-ups / 100 squats.
- Weekend test scores are continuous-set results, not daily exercise totals.
- You may record a trial on any day; Friday and Saturday are recommended.
- Rank E (0 weeks), D (1), C (3), B (6), A (9), S (12).

No automatic sensor, video, or Apple Health verification is included in V1. All rep reporting is manual.
